# DataObj 사용법

## 정의

상속만 하면 정의 시점에 자동으로 dataclass가 된다. 데코레이터를 붙이지 않는다.

```python
class Cursor(DataObj):
    id: str
    position: Point      # 중첩 DataObj 가능
    score: int
```

- 옵션 조절: `__dataclass_config__ = dict(frozen=True, ...)`
- 자동화 해제: `__auto_dataclass__ = False`

## 직렬화 규약 (to_dict / from_dict)

```python
cursor_dict = cursor.to_dict()
restored = Cursor.from_dict(cursor_dict)
```

- from_dict는 타입 힌트를 해석해 중첩 DataObj, `list[T]`, `X | None` 필드를 복원한다.
  `from __future__ import annotations` 모듈에서도 동작한다.
- to_dict를 오버라이드해 외부 표현을 바꾸면(예: Cursor가 width/height 제거) from_dict 왕복이 깨질 수 있다. 오버라이드 시 둘을 쌍으로 관리한다.

## copy 규약

```python
snapshot = cursor.copy()   # 필드 단위 재귀 복사
```

- obj를 Handler 밖으로 내보낼 때, 저장할 때 모두 copy를 거친다.
  ([data](/docs/Glossary/dev/data.md)는 immutable snapshot — 원본 참조가 새면 외부에서 내부 상태를 변경할 수 있다)
