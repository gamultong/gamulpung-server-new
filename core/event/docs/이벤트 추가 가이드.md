# 이벤트 추가 가이드

새 이벤트 하나를 추가할 때 건드려야 하는 곳의 전체 목록. scope 개념은 [event](/docs/Glossary/dev/event.md) 참고.

## 1. enum에 멤버 추가 (data/event)

```python
class InternalEvent(InternalBase, EventEnum):
    NOTIFY_CURSORS = auto()   # 값은 "NOTIFY-CURSORS"로 자동 변환된다 (_ → -)
```

- 이름 규칙(대문자+하이픈)은 메커니즘이 강제하므로 auto()만 쓰면 된다.
- data/event/test의 명명 테스트가 멤버 목록을 검증한다 — 기대 목록에 새 멤버를 추가한다.

## 2. ClientEvent라면: payload 매핑 추가

- 외부 payload를 data/payload/external에 정의한다. (/data/payload/docs/작성%20가이드.md)
- **data/conn의 message.py에 있는 이벤트→payload match 분기에 case를 추가한다.**
  빠뜨리면 해당 이벤트 수신 시 InvalidEvent_Exception이 발생한다.

## 3. Receiver 작성

- 디렉토리는 scope와 1:1이다: receiver/external=Client, internal=Internal, trigger=Trigger.
- 1파일 = 1이벤트 = 1함수 템플릿을 따른다. ([HR 구현 가이드](/docs/Other/Convention%20guide/HR.md))
- receiver 없는 이벤트를 publish하면 KeyError가 난다. (/core/broker/docs/사용법.md)

## 4. 발행 지점 연결

- 상태 변화에서 도출되는 이벤트면 Emitter에 발행 규칙을 등록한다. ([[RFC-009] Emitter](/docs/RFC/%5BRFC-009%5D%20Emitter.md))

## scope 선언 (새 scope를 만들 때만)

```python
class InternalBase(ScopedBase):
    __scope_part__ = "INTERNAL"   # 부모 scope에 누적된다
```
