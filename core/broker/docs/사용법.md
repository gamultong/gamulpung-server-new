# EventBroker 사용법

## 등록과 발행

```python
# Receiver 등록 (import 부수효과로 동작 — server.py가 import를 보장한다)
@EventBroker.add_receiver(ClientEvent.MOVE)
async def move_receiver(event):
    ...

# 발행 (Handler만 수행한다)
await EventBroker.publish(event)
```

## 발행 의미론

- 등록된 receiver들을 **동시 실행**하며 전부 끝날 때까지 await한다.
- receiver 간 **실행 순서는 보장하지 않는다**. 순서에 의존하는 로직을 쓰지 않는다.
- receiver의 예외는 publish 호출자(Handler)로 전파된다. 단 다른 receiver는 계속 실행되고
  추가 Event는 발행되지 않는다 — 이것이 격리 기준이다. ([[ADR-005] 데이터 정합성 수준 채택](/docs/ADR/%5BADR-005%5D%20데이터%20정합성%20수준%20채택.md))

## 주의

- receiver가 하나도 등록되지 않은 이벤트를 publish하면 KeyError가 난다.
  새 이벤트를 만들면 receiver를 함께 작성한다. (/core/event/docs/이벤트 추가 가이드.md)
- `is_end()`는 처리 중 이벤트가 없는지 확인하는 종료 판단용이다. 일반 로직에서 쓰지 않는다.
