# RFC 작성 가이드
- `docs/RFC/`에 저장한다.
- 파일 이름은 `[RFC-XXX] Title`의 형태로 작성한다.
- 규칙·원칙·구조를 bullet 형태로 명확히 적는다.
- 이미지, ADR 링크, 관련 문서는 설명하는 위치에 직접 배치한다.
- 참조 섹션은 사용하지 않는다.

## 형식
```md
# 제목

## 목적
이 RFC가 다루는 전역 영향의 결과를 명확히 적는다.
해당 논의가 어떤 전역 규칙/구조/원칙을 정의하는지 한 문단으로 요약.

## 규칙
전역적으로 적용되는 결과(규칙/정책/구조)를 bullet로 명확히 기술.
- 규칙 1
- 규칙 2
- 규칙 3

(관련 이미지가 있다면 규칙 설명 바로 아래 삽입)
(관련 ADR이 있다면 해당 규칙 설명 옆에 인라인 링크)

## 적용 범위
이 규칙이 적용되는 영역.
(모듈/도메인/레이어 전체 적용인지, 특정 기술 군에만 적용인지 등.)
```
