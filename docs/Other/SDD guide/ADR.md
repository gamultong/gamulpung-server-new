# ADR 작성 가이드
- `docs/ADR/`에 저장한다.
- 파일 이름은 `[ADR-XXX] Title`의 형태로 작성한다.
- `상황 / 결정 / 근거`를 짧게 요약한다.
- PR/Commit/이슈 링크는 근거 설명에 인라인으로 삽입한다.
- 관련 RFC는 결정 또는 근거에 인라인으로 링크한다.

## 형식
```md
# 제목

## 상황
이 결정을 남겨야 하는 이유(구두/비추적 논의 등)의 요약.

## 결정
최종 선택 사항을 한 줄로 표현. (관련 RFC가 있다면 여기 인라인 링크)

## 근거(요약)
핵심 이유를 3~5줄 이내로 압축.
(PR/Commit/이슈 링크는 관련 문장에 인라인으로 삽입)
```
