# 지뢰 설치
관련 문서:
- /docs/Other/API_spec/WebSocket/Client/INSTALL-BOMB.md
- /docs/Other/API_spec/WebSocket/Server/BOMB-POSITION.md

## 시나리오
1. 사용자가 보유한 폭탄을 사용하여 특정 tile에 지뢰 설치를 요청한다.
2. 변경된 cursor 정보가 전달된다.
3. 설치 지점을 보는 cursor에게 설치 사실이 전달된다.
4. 해당 타일에서 일정 시간이 지나면 지뢰가 폭발하여 explosion이 발생한다.
5. 폭발 범위 내 열린 tile의 색이 설치자 색으로 변경된다.
6. 변경된 tile 정보가 전달된다.

## 비즈니스 규칙
- 접속중인 사용자만 지뢰 설치가 가능하다. ([FT-006](/docs/Feature/[FT-006]%20접속.md) 참조)
- 죽은 cursor는 지뢰를 설치할 수 없다.
- 폭탄 보유량이 1 미만이면 지뢰를 설치할 수 없다.

## 상태 변화
- cursor 폭탄 보유량: n → n-1
- 폭발 범위 내 cursor 상태: alive → dead
- 폭발 범위 내 열린 tile 색: 기존 색 → 설치자 색
