# 타일 열기

## 시나리오
1. 사용자가 closed-tile을 클릭하여 열기를 요청한다.
2. tile이 opened 상태로 변경되고 지뢰 정보가 표시된다.
3. 지뢰가 있는 경우 explosion이 발생한다.

## 비즈니스 규칙
- flag가 설치된 tile은 열 수 없다.
- 접속중인 사용자만 가능
- closed-tile만 열기 가능하다.
- 죽은 cursor는 타일을 열 수 없다.

## 상태 변화
- tile 상태: closed → opened
- 지뢰 발견 시 cursor 상태 변경
