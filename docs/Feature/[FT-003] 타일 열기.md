# 타일 열기

## 목적
사용자가 closed-tile을 열어 지뢰 정보를 확인하거나 게임을 진행할 수 있는 기능을 제공한다.

## 시나리오(Use Case)
- UC-1: 사용자가 closed-tile을 클릭하여 열기를 요청한다.
- UC-2: tile이 opened 상태로 변경되고 지뢰 정보가 표시된다.
- UC-3: 지뢰가 있는 경우 explosion이 발생한다.

## 행동(Behavior)
사용자가 closed-tile을 클릭하면 해당 tile이 열리며 주변 지뢰 수가 표시된다. ([[RFC-007] Interaction](/docs/RFC/%5BRFC-007%5D%20Interaction.md)) 만약 지뢰가 있다면 explosion이 발생하고 cursor 상태가 변경된다. ([EXPLOSION API](/docs/Other/API_spec/WebSocket/Server/EXPLOSION.md))

## 입력 (Input)
- 타일 위치 좌표 (x, y) ([API spec](/docs/Other/API_spec/WebSocket/Client/OPEN-TILES.md))

## 출력 (Output)
- TILES-STATE: 변경된 tile 정보 (opened 상태, 지뢰 수) ([API spec](/docs/Other/API_spec/WebSocket/Server/TILES-STATE.md))
- 지뢰 발견 시:
  - EXPLOSION: explosion 정보 ([API spec](/docs/Other/API_spec/WebSocket/Server/EXPLOSION.md))
  - CURSORS-STATE: cursor 상태 변경 ([API spec](/docs/Other/API_spec/WebSocket/Server/CURSORS-STATE.md))

## 비즈니스 규칙(Business Rule)
- flag가 설치된 tile은 열 수 없다.
- 지뢰가 있는 tile을 열면 explosion이 발생한다.
- closed-tile만 열기 가능하다.

## 상태 변화(State)
- tile 상태: closed -> opened
- 지뢰 발견 시 cursor 상태 변경 (게임오버 등)
