# 커서 생성

## 목적
사용자가 게임에 참여할 때 Board 상의 특정 위치에 자신의 cursor를 생성하는 기능을 제공한다.

## 시나리오(Use Case)
- UC-1: 최초 접속 시 초기 위치에 cursor를 생성한다.
- UC-2: 재접속 시 원하는 위치를 지정하여 cursor를 생성한다.
- UC-3: 생성된 cursor 정보가 다른 사용자들에게 전달된다.

## 행동(Behavior)
사용자가 연결 후 CREATE_CURSOR를 발행하면 지정된 위치에 cursor가 생성된다. 생성된 cursor는 시야 범위 내의 다른 사용자들에게 전달된다.

## 입력 (Input)
- 초기 위치 좌표 (x, y) - 선택적 ([API spec](/docs/Other/API_spec/WebSocket/Client/CREATE-CURSOR.md))
- 미제공 시 기본 위치 (0, 0) 사용

## 출력 (Output)
- CURSOR_CREATED: 생성된 cursor의 전체 정보 ([API spec](/docs/Other/API_spec/WebSocket/Server/CURSOR-CREATED.md))
- CURSORS_STATE: 주변 사용자들에게 새 cursor 알림 ([API spec](/docs/Other/API_spec/WebSocket/Server/CURSORS-STATE.md))

## 비즈니스 규칙(Business Rule)
- cursor는 연결당 한 번만 생성된다.
- 초기 위치는 opened-tile이어야 한다 (현재는 (0,0)이 항상 열려있음).
- 동일 ID로 중복 생성 시도는 무시된다.
- cursor 생성 후 시야 설정([FT-005] 시야 설정)을 해야 게임에 참여할 수 있다.

## 상태 변화(State)
- CursorHandler에 새 cursor 추가
- 생성 시점의 timestamp 기록 (active_at)
- 초기 score는 0으로 설정
- 초기 viewport는 0x0 (시야 설정 전)
