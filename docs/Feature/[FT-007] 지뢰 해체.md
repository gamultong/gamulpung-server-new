# 지뢰 해체

## 시나리오
1. 사용자가 flag-tile을 홀딩(hold) 하여 지뢰 해체를 요청한다.
2. tile이 opened 상태로 변경되고 지뢰 정보가 표시된다.
3. 지뢰가 있는 경우 cursor가 지뢰 1개를 획득한다.
4. number가 0인 타일이 opened 되는 경우 chaining이 발생한다.
5. 변경된 tile 정보가 전달된다.
<!-- - 지뢰가 없는 경우에 패널티를 부과할 수도 있다. -->


## 비즈니스 규칙
- 접속중인 사용자만 가능하다.
- 죽은 cursor는 지뢰 해체를 수행할 수 없다.
- flag-tile에서만 지뢰 해체를 요청할 수 있다.  

## 상태 변화
- tile 상태: closed → opened
- tile flag 상태: true → false (해체 완료 시 깃발 자동 해제)
- cursor: 지뢰 보유량 +1
