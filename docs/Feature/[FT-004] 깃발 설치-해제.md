# 깃발 설치-해제

## 시나리오

### 깃발 설치
1. 사용자가 깃발이 없는 닫힌 타일에 깃발 설치를 요청한다.
2. 타일에 깃발이 설치된다.
3. 변경된 타일 정보가 전달된다.

### 깃발 해제
1. 사용자가 깃발이 있는 타일에 깃발 해제를 요청한다.
2. 타일의 깃발이 제거된다.
3. 변경된 타일 정보가 전달된다.

## 비즈니스 규칙

### 깃발 설치
- 닫힌 타일에만 깃발을 설치할 수 있다.

### 깃발 해제
- 깃발이 있는 타일에서만 해제할 수 있다.

### 공통
- 죽은 cursor는 깃발을 설치/해제할 수 없다.
- 접속중인 사용자만 가능 ([FT-006](/docs/Feature/[FT-006]%20접속.md) 참조)
- 깃발이 설치된 타일은 열 수 없다. ([FT-003](/docs/Feature/[FT-003]%20타일%20열기.md) 참조)

## 상태 변화
- 깃발 설치: 타일의 flag 상태 false → true
- 깃발 해제: 타일의 flag 상태 true → false
