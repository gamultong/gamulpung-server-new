# 시야 설정

## 시나리오

1. 사용자가 시야 크기(width, height)를 설정한다.
2. 변경된 시야 범위에 따라 tile 및 cursor 정보가 업데이트된다.

## 비즈니스 규칙

- 접속중인 사용자만 가능 ([FT-006](/docs/Feature/[FT-006]%20접속.md) 참조).
- 시야 범위는 변경 가능하나 무한하지 않다.
- 시야 범위 내의 객체만 관측 가능하다.

## 상태 변화

- cursor의 시야 범위 설정이 변경된다.
