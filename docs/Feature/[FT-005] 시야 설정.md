# 시야 설정

## 목적
사용자가 자신의 시야 범위를 조정할 수 있는 기능을 제공한다.

## 시나리오(Use Case)
- UC-1: 사용자가 시야 크기(width, height)를 설정한다.
- UC-2: 변경된 시야 범위에 따라 tile 및 cursor 정보가 업데이트된다.

## 행동(Behavior)
사용자가 시야 크기를 변경하면, 새로운 시야 범위 내의 tile과 다른 cursor 정보가 전달된다. ([[RFC-007] Interaction](/docs/RFC/%5BRFC-007%5D%20Interaction.md))

## 입력 (Input)
- 시야 범위([API spec](/docs/Other/API_spec/WebSocket/Client/SET-WINDOW.md))

## 출력 (Output)
- TILES-STATE: 새로운 시야 범위 내의 tile 정보 ([API spec](/docs/Other/API_spec/WebSocket/Server/TILES-STATE.md))
- CURSORS-STATE: 새로운 시야 범위 내의 cursor 정보 ([API spec](/docs/Other/API_spec/WebSocket/Server/CURSORS-STATE.md))

## 비즈니스 규칙(Business Rule)
- 시야 범위는 변경 가능하나 무한하지 않다.
- 시야 범위 내의 객체만 관측 가능하다.

## 상태 변화(State)
- cursor의 시야 범위 설정이 변경된다.
