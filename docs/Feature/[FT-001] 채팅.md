# 채팅

## 목적
사용자가 다른 사용자와 텍스트 메시지를 주고받을 수 있는 기능을 제공한다.

## 시나리오(Use Case)
- UC-1: 사용자가 채팅 메시지를 전송한다.
- UC-2: 해당 사용자를 시야 내에 두고 있는 다른 사용자들이 메시지를 수신한다.

## 행동(Behavior)
사용자가 채팅 메시지를 전송하면, 해당 사용자의 cursor를 시야에 두고 있는 모든 사용자에게 메시지가 전달된다.

## 입력 (Input)
- 메시지 내용 (문자열) ([API spec](/docs/Other/API_spec/WebSocket/Client/CHAT.md))

## 출력 (Output)
- 발신자 정보와 메시지 내용 ([API spec](/docs/Other/API_spec/WebSocket/Server/CHAT.md))

## 비즈니스 규칙(Business Rule)
- 메시지는 발신자의 cursor를 볼 수 있는 사용자에게만 전달된다.
- 시야 범위 밖의 사용자는 메시지를 수신하지 못한다.

## 상태 변화(State)
- 메시지 전송 시 상태 변화 없음 (일회성 이벤트)
