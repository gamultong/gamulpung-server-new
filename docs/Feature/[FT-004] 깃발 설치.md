# 깃발 설치

## 목적
사용자가 지뢰가 있다고 판단되는 tile에 깃발을 설치하거나 해제할 수 있는 기능을 제공한다.

## 시나리오(Use Case)
- UC-1: 사용자가 closed-tile에 깃발 설치/해제를 요청한다.
- UC-2: 깃발이 없으면 설치되고, 있으면 해제된다.
- UC-3: tile 상태 정보가 업데이트된다.

## 행동(Behavior)
사용자가 closed-tile을 우클릭하면 깃발이 토글된다. ([[RFC-007] Interaction](/docs/RFC/%5BRFC-007%5D%20Interaction.md)) 깃발이 설치된 tile은 열 수 없다.

## 입력 (Input)
- 타일 위치 좌표 (x, y) ([API spec](/docs/Other/API_spec/WebSocket/Client/SET-FLAG.md))

## 출력 (Output)
- TILES-STATE: 변경된 tile 정보 (깃발 설치/해제 상태) ([API spec](/docs/Other/API_spec/WebSocket/Server/TILES-STATE.md))

## 비즈니스 규칙(Business Rule)
- closed-tile에만 깃발을 설치할 수 있다.
- 깃발이 있으면 해제, 없으면 설치한다 (토글).
- 깃발이 설치된 tile은 열 수 없다.

## 상태 변화(State)
- tile의 flag 상태가 토글된다.
