# 커서 이동

## 시나리오
1. 사용자가 특정 위치로 이동을 요청한다.
2. cursor 위치가 변경되고 점수가 1 증가한다.
3. 변경된 위치 기준으로 새로운 tile 및 bomb, cursor 정보가 전달된다.

## 비즈니스 규칙
- opened-tile로만 이동 가능하다.
- 접속중인 사용자만 가능 ([FT-006](/docs/Feature/[FT-006]%20접속.md) 참조)
- 죽은 cursor는 이동할 수 없다.

- cursor의 position이 변경된다.
- cursor의 score가 1 증가한다.
