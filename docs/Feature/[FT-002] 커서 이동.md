# 커서 이동

## 목적
사용자가 자신의 cursor를 Board 상에서 이동시킬 수 있는 기능을 제공한다.

## 시나리오(Use Case)
- UC-1: 사용자가 특정 위치로 이동을 요청한다.
- UC-2: cursor 위치가 변경되고 시야 범위가 이동한다.
- UC-3: 시야 범위 변경에 따라 새로운 tile 및 cursor 정보가 전달된다.

## 행동(Behavior)
사용자가 opened-tile을 클릭하면 해당 위치로 cursor가 이동한다. ([[RFC-007] Interaction](/docs/RFC/%5BRFC-007%5D%20Interaction.md)) 이동 시 시야 범위가 함께 이동하며, 새로운 시야 범위 내의 정보가 업데이트된다.

## 입력 (Input)
- 목표 위치 좌표 (x, y) ([API spec](/docs/Other/API_spec/WebSocket/Client/MOVE.md))

## 출력 (Output)
- CURSORS-STATE: 변경된 cursor 위치 정보 ([API spec](/docs/Other/API_spec/WebSocket/Server/CURSORS-STATE.md))
- TILES-STATE: 새로운 시야 범위 내의 tile 정보 ([API spec](/docs/Other/API_spec/WebSocket/Server/TILES-STATE.md))

## 비즈니스 규칙(Business Rule)
- opened-tile로만 이동 가능하다.
- 상호작용 범위 밖 클릭 시 경로상 반복 이동이 가능하다.

## 상태 변화(State)
- cursor의 position이 변경된다.
- 시야 범위가 이동한다.
