# Color 유추적 특정성 채택

## 상황
프로젝트 모토는 "불특정 다수의 인터랙션"으로, cursor color를 없애는 방향을 검토했다. 그러나 color를 없애면 사용자가 다른 커서를 인지할 가시성이 사라진다.

## 결정
color의 가짓수를 줄이고 중복을 허용한다. 사용자를 완전히 특정할 수는 없지만 유추할 수 있는 수준("방금 그 노란 커서" 정도)의 특정성만 제공한다.

## 근거(요약)
- 익명성(불특정 다수)과 가시성(커서 인지)을 동시에 만족해야 했다.
- color 중복 허용은 완전 특정을 막으면서 유추적 특정성을 남긴다.
- 이에 따라 color 중복 검사를 제거했다.
