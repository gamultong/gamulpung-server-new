# 데이터 정합성 수준 채택

## 상황
다단계 쓰기의 트랜잭션 경계와 Event 처리 실패의 복구 수준을 정해야 했다. 저장소는 함수 호출 단위로 commit하며, Event 처리 실패에 대한 재시도·보상 처리는 없다.

## 결정
Handler·Receiver 실행을 원자성 단위로 보고, 그 이상의 트랜잭션 경계나 Event 실패 복구 장치를 두지 않는다. 실패는 발생한 단계에서 종료한다.

## 근거(요약)
- 실패는 발생한 단에서 끝나야 하며, 상위로 번지는 복구 흐름은 복잡성을 키운다.
- 게임 도메인 특성상 강한 데이터 정합성이 필수적이지 않다.
- 단순성을 우선한다.
