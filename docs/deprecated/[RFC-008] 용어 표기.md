## 프로젝트 용어
흔히 사용되는 표현이 아닌 프로젝트 내에 다른 의미로 사용된 용어는 `Name`의 형태로 정의됩니다.
이는 주로 프로젝트 내에 Obj나 특수한 용어를 의미합니다.
또한 대부분 RFC의 용어 설명에 정의되어 있습니다.

## 인자 표기
편의를 위해 사용되는 인자의 표현은 `<arg>`의 형태입니다.
인자의 값을 설명할 경우 다음과 같이 표기합니다:

`<arg>` -> value

또는

`<arg>`
```
value
```
