# 문서화

이 문서는 Gamulpung Server의 문서화 가이드 입니다.

## Module
Module은 소스코드 집합입니다. ([참고1](3.%20Module.md))
Module의 루트에 `README.md`에 모듈의 정보를 적습니다.
또한 관련 문서를 Module 루트에 `docs/`에 명시하여 주세요.
만일 프로젝트 전반에 필요한 정보라면, 프로젝트 루트 `docs/`에 적고 모듈 `README.md`를 참조로 달아주세요.
`README.md`의 작성은 밑을 참조해주세요.

## RFC
RFC는 프로젝트 전반적으로 의논된 컨셉, 제약 사항을 기술합니다.
`docs/RFC`에 작성되며, 작성 시기별로 넘버링합니다.

## 기타 문서
이외 많은 문서들이 작성 될 수 있습니다.
이외 문서작성에 관하여 RFC를 작성하고, 문서에 참조를 달아주세요.

## README.md
`README.md`는 해당 범위에 들어가면 가장 먼저 봐야 할 문서입니다.
`README.md`를 작성 할 때에는 해당 범위를 명확히 명시해 주세요.
또한 관련 문서로 자연스레 넘어갈 수 있도록 관련 문서 경로를 명시해 주세요.
