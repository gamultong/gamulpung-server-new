# Section 생성 및 numbering

이 문서는 `Section`의 생성 및 `numbering` 방식의 관한 설명입니다.

## 용어 정의
- `numbering` : 지뢰 수 계산(혹은 계산됨)
- `closed section` : 단순 생성 `section`(`numbering` X)
- `numbering section` : numbering 된 `section`
- `interaction section`  : 상호작용 가능한 `section`

## section 생성 방법
1. `numbering section`에 상호작용한다.
2. `numbering section`을 `interaction section`으로 격상하여 상호작용에 응답한다.
3. `numbering section` 주변 1칸의 `closed section`을 `numbering section`으로 격상한다.

### `closed section` -> `numbering section`
1. 주변 1칸의 `section`이 없다면 그 자리에 `closed section`을 생성한다.
2. 자신을 `numbering`한다.

## 의도 및 목적
맵 생성에 있어 완충지대를 두어 빠르게 사용자에게 응답하기 위함이다.

이전 방법
> `요청 -> 생성 -> 응답`
재시 방법
> `(미리 생성됨) -> 요청 -> 다음 생성 예약 -> 응답`

## 기타
`Section`은 주변 `Section`의 상태 flag를 가진다.
