# Interaction

이 문서는 사용자 상호작용에 대한 설명이다.

## Intriduce
상호작용은 사용자가 Object의 영구/비영구 적 변화를 주는 행위를 의미한다.

## Object
- `cursor` : 사용자가 조종하는 케릭터이다.
- `tile` : 타일이다. 이는 다음과 같은 상태를 가진다.
    - `closed` : 닫혀있는 타일이다. 이는 지뢰를 포함할 수 있다.
    - `opened` : 열려있는 타일이다. 이는 지뢰의 관한 정보를 포함할 수 있다 
- `flag` : 깃발이다.

### cursor
상호작용의 주체는 사용자를 대변하는 `cursor`를 통해 이루어지며,
이는 사용자당 1개의 `cursor`를 부여된다.

cursor는 다음과 같은 제약사항을 가지고 있다.
- 시야범위 : 커서는 시야범위를 가지며 이에 들어온 Object만 관측 가능하다. 이는 변경할 수 있으나 무한하지 않다.
- 상호작용 범위 : 커서는 상호작용 범위를 가지며 상호작용은 상호작요 범위 안에서만 가능하다. 이 범위는 주위 1칸이다. 다만 예외가 있을 수 있다.

## 상호작용
상호작용은 다음과 같은 것이 있을 수 있다.
- 이동
- 타일 열기
- 깃발 설치/해제

### 이동
이동은 `opened-tile`을 좌클릭할 시 발생한다.
이는 `cursor`의 위치를 이동시킨다.

이동은 `opened-tile`으로만 이동 가능하다.

이는 상호작용 범위 내에서만 가능하나, 편의성을 위해 상호작용 범위 밖을 클릭하여도 이동을 반복해 갈 수 있다면, 이를 반복하여 위치를 옮길 수 있다.

### 타일 열기
타일 열기는 `closed-tile`을 좌클릭할 시 발생한다.
이는 `closed-tile`을 `opened-tile`로 변경시킨다.

그러나 타일에 지뢰가 있다면 `explosion`이 일어난다.
타일에 `flag`가 있다면 타일 열기를 할 수 없다.

### 깃발 설치/해제
깃발 설치는 `closed-tile`을 우클릭 할 시 발생한다.
이는 `closed-tile`에 `flag`를 설치한다.
이미 `flag`가 설치되었다면 `flag`를 해제한다.
