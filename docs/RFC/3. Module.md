# Module

이 문서는 Module의 구조를 설명하기 위해 작성되었습니다.

## Introduce
Module은 소스코드 집합입니다.

이는 소스코드의 구조 적립과 원활한  Python import를 위해 고안되었습니다.
- export를 명시하여 ide 자동작성을 원활히 사용하고, 의도치 않은 unit 사용을 막음

## 구조
```
<module>/
    <sub-module>/
    internal/
        <source1>
        <source2>
    test/
        <test1>
        <test2>
    docs/
        <docs1>
        <docs2>
    __init__.py
    README.md
```
- `<submodule>/` : 하위 모듈입니다. 중첩 구조를 위해 고안되었습니다.
- `internal/` : 소스코드를 작성하는 곳 입니다.
- `test/` : module의 대한 test를 작성하는 곳 입니다.
- `docs/` : module의 대한 세부정보를 작성하는 곳 입니다.
- `__init__.py` : module의 export를 명시하는 곳 입니다.
- `README.md` : module의 문서 및 소개입니다.
