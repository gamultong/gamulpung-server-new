# Board와 좌표 체계

## 목적
무한 크기의 2차원 지뢰찾기 맵과 좌표 체계를 정의한다.

## 규칙
- Board는 무한 크기의 2차원 평면이다.
- Board 중심은 (0, 0)이다.
- Section은 100x100 크기의 Tile 집합이다.
- Section 좌표는 `sec(x, y)` 형식으로 표기한다.
- 지역 좌표는 `rel(x, y)` 형식으로 표기한다 (Section 내부 좌표).
- 범위 접근 시 좌상~우하 좌표를 명시한다.

### Section 좌표 예시
- (0, 0) Tile을 포함하는 Section: sec(0, 0)
- sec(0, 0) 범위: (0, 0) ~ (99, 99)

## 적용 범위
Board 관련 모든 구현에 적용된다.
